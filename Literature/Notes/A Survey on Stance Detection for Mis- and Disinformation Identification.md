- **Stance detection**: understanding attitudes expressed in text
	  - input, target text. Classify as Favor, Against, Neither, Neutral
	  - for a textual input and a rumour expressed as text, stance detection here is to determine the position of the text towards the rumour as a category label from the set {Support, Deny, Query, Comment}.
- Stance: expression of a speaker´s standpoint and judgment towards a given proposition
- Other useful NLP tasks: biased language detection, emotion recognition, perspective identification, sarcasm detection, sentiment analysis
